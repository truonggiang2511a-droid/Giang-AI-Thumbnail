# Giang AI Thumbnail

AI Thumbnail Studio cho YouTube, tập trung môi giới BĐS.

## Chạy local
1. `npm install`
2. copy `.env.example` thành `.env.local`
3. thêm `GEMINI_API_KEY`
4. `npm run dev`

Model image mục tiêu: `gemini-3.1-flash-image` (Nano Banana 2). UI hiện đã có upload, hook lab, style presets, CTR mock score và API route server-side để tích hợp Gemini.
